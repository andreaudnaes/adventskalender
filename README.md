# Adventskalender 2026

Hvis du er Erlend, IKKE SE!
En personlig adventskalender med en ny gåte bak hver luke.

- `index.html`: siden
- `style.css`: utseendet (burgunder og gull)
- `app.js`: lukene, datoene og hvilket spill som ligger bak hver luke

## Teste

Legg til `?test=6` bak adressen for å se kalenderen som om det er 6. desember.
Sett `TEST_MODE` til `false` øverst i `app.js` før kalenderen sendes.
